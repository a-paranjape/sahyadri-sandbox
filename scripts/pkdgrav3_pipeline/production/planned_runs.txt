# Planned Sahyadri runs, read by the run manager (tools/sahyadri_manager) every few minutes. Template: the manager's
# copy is ~/.sahyadri_mgr/planned_runs.txt (made from this file on first start); edit that one. Which queues take jobs,
# and their own limits: ~/.sahyadri_mgr/queues.txt (template queues.txt here).
# For each line not yet set up, the manager runs setup_production.py on the site (pawna locally, pegasus over ssh),
# registers the run and puts its simulation in the queue with this priority (lower first). Runs then start as the
# limits, scratch space and (pegasus) core-hour budget allow. Editing a line's priority re-prioritises a run that is
# still waiting. Removing a line (or moving it to another site) makes the manager forget the run that line set up,
# if it never started (no job, no event): it leaves the manager, its set-up files stay. A run that started is kept
# (unschedule or remove it in the page).
#
# columns:  site     queue    cosmology  N     L      realisations  priority  [options]
#   site      pawna | pegasus | swarm | leap
#   queue     pawna: workq;  pegasus: project (project budget hpc2502016, 96 h jobs) | regular (user budget, 48 h)
#             | debug (tests, 4 h);  swarm: workq (72 h, shared nodes);  leap: workq (72 h; 2048^3 on 6 fabric nodes)
#   cosmology a name in cosmologies/ (default, var_As_m, var_Om_p, ...)
#   realisations  1 | 1,3 | 1-5
#   options   hold                 set up and register, paused (start from the page)
#             not_before=YYYY-MM-DDTHH:MM   keep_full_z="0 0.5 1"   keep_pct=1   root=DIR   archive=DIR
#             nodes=4 (pegasus simulation nodes)   rs_batch=0 (Rockstar only after the simulation)
#             rs_nodes=2 (pegasus: Rockstar nodes; default the fewest for its memory at <= 360 GB each, 2 at 2048^3)
#             gpu=1 (pegasus: simulation on the GPU nodes with the CUDA build; nodes default 3 from 2048^3, else 1;
#                    queue regular or project, not debug: the debug queue has no GPU nodes)
#             post_site=pride (swarm, leap: halo stages rockstar ... verify on pride, which shares /user1; the
#                    manager runs post_site_conf.py on pride before registering the run. Needed on leap, which
#                    has no Rockstar. Only for a run set up from this line; an older run: see the README)
#   examples
#   leap     workq    default    2048  200  101    0         post_site=pride keep_pct=9
#   swarm    workq    default    2048  200  102    0         post_site=pride keep_pct=9
# Runs above 512^3 need approval: add them here only once approved.
#
# site     queue    cosmology  N     L    reals  priority  options
